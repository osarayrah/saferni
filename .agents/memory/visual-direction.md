---
name: Safferni visual direction
description: The approved visual identity that future mobile UI work should preserve.
---

Safferni uses a clean white-led visual identity with deep travel blue primary actions, blue-tinted neutral surfaces, and the supplied Safferni symbol as the primary brand mark across web and mobile. Gold remains a subtle detail within the supplied artwork rather than an interface accent.

**Why:** The user explicitly replaced the prior dark luxury direction with white as the main color and blue accents, and supplied the final logo and application-icon artwork.

**How to apply:** Keep new and revised screens predominantly white with accessible Safferni blue actions and restrained blue-tinted borders/surfaces. Use the supplied symbol artwork rather than an improvised lettermark or unrelated icon.
